# 🚀 AI Interview Prep Simulator

An AI-powered interview preparation platform designed to simulate real-world technical and behavioral interviews. Built with a robust **Java Spring Boot** backend and a responsive **React** frontend, this application provides users with real-time feedback, personalized question generation, and comprehensive performance analytics.

---

## ✨ Features

* **🤖 AI Mock Interviews:** Generates role-specific interview questions using AI (e.g., Software Engineering, Data Science, Product Management).
* **🎙️ Speech-to-Text Integration:** Practice verbal responses with real-time transcription.
* **📊 Instant Feedback & Scoring:** Get actionable insights on your answers, including clarity, technical accuracy, and tone.
* **📈 Progress Tracking:** Dashboard to track performance history and identify areas for improvement.
* **🔐 User Authentication:** Secure login and profile management.

---

## 🛠️ Tech Stack

### Frontend
* **Framework:** [React.js](https://reactjs.org/)
* **State Management:** Redux / Context API
* **Styling:** Tailwind CSS / Material-UI
* **HTTP Client:** Axios

### Backend
* **Framework:** [Spring Boot](https://spring.io/projects/spring-boot) (Java)
* **Build Tool:** Maven / Gradle
* **Security:** Spring Security & JWT (JSON Web Tokens)
* **AI Integration:** Gemini API (or alternative LLM providers)
* **Database:** PostgreSQL / MySQL
